# FlareRapids Studio Website

The official website for **FlareRapids**, a global mobile studio building casual games, daily utility apps, and bespoke mobile management applications.

**Live site:** https://flarerapids.com

## Tech Stack

- **HTML5** — semantic markup, structured data (JSON-LD), full SEO meta
- **CSS3** — custom design system, no framework dependency, rich animations
- **Vanilla JavaScript** — no build step, all interactions
- **SVG** — all icons, logo, decorative graphics
- **PNG** — generated hero / showcase imagery

## Structure

```
/
├── index.html            # Home
├── services.html         # Services
├── contact.html          # Contact
├── privacy.html          # Privacy Policy
├── terms.html            # Terms of Service
├── 404.html              # Not found
│
├── css/
│   └── style.css         # Global styles
│
├── js/
│   └── main.js           # Animations & interactions
│
├── images/
│   ├── svg/              # Icons, logo, decorative SVGs
│   └── png/              # Hero / showcase images
│
├── .well-known/
│   └── security.txt      # Security disclosure
│
├── app-ads.txt           # Authorized ad sellers
├── robots.txt            # Crawler rules
└── sitemap.xml           # Sitemap
```

## Deployment

Deployed via GitHub Pages. Any commit to the default branch triggers a new build.

## Editing

- **Content:** edit the relevant HTML file.
- **Styles:** `css/style.css` is the only stylesheet; design tokens at the top.
- **Behavior:** `js/main.js` is the only script.
